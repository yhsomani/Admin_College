# Admin College App Design System

## Overview
This design system provides a unified, modern look for the Admin College application.

## Colors
- **Primary**: Deep Blue (#0D47A1)
- **Background (Light)**: Off-white (#F8F9FA)
- **Background (Dark)**: Dark Grey (#121212)

## Typography
- **Font Family**: Inter

## Components
- Cards and buttons should have rounded corners for a softer, modern aesthetic.
- Use clear, legible font sizes and weights to differentiate hierarchy.
